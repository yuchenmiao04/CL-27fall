# 方案设计

## 1. 研究主线

老师原始主线是：有原则地分解预测问题，使所得子问题或知识单元在任务流中复用；任务改变时，分解及学习规则可以适应。分解可以是无人工语义的潜在结构，由系统自行学习，不要求外部回答模型。轻量计算、可解释性及快速适应属于待检验潜力。

本轮围绕固定容量共享结构实现四个候选路线。共享对象可以是预测器空间的低秩先验，也可以是中间 token 上的模块库。相近文献是理解、比较与改进的起点；不因相似就提前缩窄问题，也不因组合已有部件就自动认定有贡献。

## 2. 与 V4 的关系

V4 的优势是通过全历史充分统计量保留全部样本作用。困难是：表示更新后，旧矩还在旧坐标；丢弃旧图像后，不能无条件精确恢复新表示的全历史矩。

| 路线 | 保留的 V4 思路 | 表示变化的处理 | 不能声称的性质 |
| --- | --- | --- | --- |
| 共享预测基 | 全历史可加矩，解析重求全部类别头 | 原始特征固定，仅改变预测器共享先验 | 不更新骨干；有限 EM 不是严格顺序无关 |
| 可塑骨干＋统计迁移 | 固定 anchor 的精确全历史矩 | 受限回放估计迁移，修正旧类均值与散度 | 当前坐标旧矩近似，非任意非线性下精确或无偏 |
| 当前模块方法适配 | anchor 全历史头，加可学习主支路 | 精确基线加受限回放中的残差学习 | 主支路非线性贡献没有精确全历史保证 |
| 可塑共享预测基 | 全历史 anchor 矩、预测器共享先验 | 先训练骨干并迁移矩，再在完整重建矩上拟合共享基 | EB 使用代理矩；未通过共享目标反向训练骨干 |

固定容量库是当前研究选择。本轮没有实现 V4 的动态分裂、e-process 出生验收或按最终测试成绩增长。先检验固定共享结构是否产生跨任务复用，再判断是否需要增长。第四方法明确组合两种机制，但这种组合的收益仍待检验。

## 3. 共享预测基

完整模型、截距、证据目标和 EM 推导见 [shared_basis.md](research/shared_basis.md)。固定特征 X、一热目标 Y 保存 `G=XᵀX`、`C=XᵀY`、特征和及类别计数。设 `w_c=D a_c+r_c`，`a_c~N(0,I)`，`r_c~N(0,epsilon I)`，故先验 `Sigma=DDᵀ+epsilon I`。消去平坦截距后：

```
S = (Gc / s² + Sigma⁻¹)⁻¹
M = S Cc / s²
Q = S + M Mᵀ / C
D_new = U_k diag(sqrt(max(q_i - epsilon, 0)))
```

最后一步是固定 epsilon、秩上限 K 的协方差 M-step。使用 `sqrt(q_i)` 会重复添加噪声底。新类到达后重求全部类别 M；旧类负样本作用通过全历史 G 进入，未拼接独立任务头。

GO-MTL / ELLA 提供潜在预测器分解和二阶历史压缩思路；经验贝叶斯与 PPCA 提供先验估计和协方差约束；ACIL / RanPAC 提供固定特征下解析累加依据。适配改变了原论文模型，详细文档逐项说明。共享基旋转不可识别；冻结 CLS 的表达上限仍可能限制性能。

## 4. 可塑骨干与历史统计迁移

完整直推 / 链式迁移、截距、cross-fitting、PSD 残差及精度预算见 [history_transport.md](research/history_transport.md)。主支路用当前图像和允许回放进行 CE 训练，CE 头是训练工具，最终部署用解析头。

固定 anchor `a(x)` 保存精确历史 G、C；主骨干 `h_t(x)` 可更新。在回放对上估计 `h_t≈aT+e`，或链式 `h_t≈h_(t-1)T+e`。驻留样本先从参考历史去除，其新特征在最终矩中精确加入，避免重复计算。

对缺失部分每类计数 n_c、旧均值 m_c 及总类内散度 S，构造：

```
m'_c = m_c T + shrink(mean_residual_c)
G'_missing = Tᵀ S T + sum_c n_c m'_cᵀm'_c + N_missing Cov_residual
C'_missing[:,c] = n_c m'_cᵀ
```

残差协方差独立收缩并保持 PSD。类均值与二阶散度修正不可互相替代。构造未保留未知参考特征与残差的交叉协方差，不能声称任意表示变化下精确；herding 与训练复用同一回放也引入选择依赖。

DPCR 已提出可塑表征、漂移估计和 ridge 分类器重构，是直接重叠工作；Coil、SLCA、FeCAM 分别提供运输、慢骨干和分布统计参照。精确 anchor、resident 替换和一致 PSD 残差需与其比较，不能只靠“统计迁移＋ridge”声称新颖。残差建模和 cross-fitting 的有效性仍需实测。

## 5. 当前固定模块库适配

完整结构、episode、带先验的残差解、旧 query 扣除和 VJP 推导见 [current_adapted.md](research/current_adapted.md)。本路线保留冻结历史统计支路、可塑主骨干及固定潜在模块库。

模块在原生 ViT 第 8、10 个 block 后作用于全部 token，每层 4 个 rank8 专家，加不修正的 null 路由。专家未预先命名语义。骨干改变共享输入表征，模块提供按输入组合的共享修正；更新用明确阶段调度。

`W0` 为 anchor 全历史 ridge 头。主特征修正采用以 W0 为中心的残差正则，`V=W0+Delta`。按类少样本 support / query 目标奖励少量标记样本支持新预测；旧 query 已在历史矩中时先精确扣除，避免其标签经解析头泄漏到自身预测。

仅凭 anchor 二阶矩无法识别可塑非线性特征的全历史交叉 Gram；主支路残差只在受限驻留样本中拟合。R2D2 的可微 ridge、AdaptFormer 的 token 残差、LAE / SLCA 的更新调度及组合式学习提供具体依据。CPU feature-chain VJP 保持链式法则，属于执行方式，仍有重算和多次微批反传成本。

当前 task-wise 多 epoch 实现允许重复优化当前样本，但 anchor 历史只在任务结束提交一次；缓存严格对应实际驻留图像身份。本轮未实现按需增长、强制语义分组或外部大模型。

## 6. 第四方法：可塑共享预测基

方法名 `plastic_shared_basis`，保留原冻结 `shared_basis`，没有改变它的骨干冻结规则、默认超参数或已有 checkpoint 结构。完整推导见 [plastic_shared_basis.md](research/plastic_shared_basis.md)，训练 / 恢复接口见 [plastic_shared_wrapper.md](research/plastic_shared_wrapper.md)，本轮阅读与独立复核见 [plastic_shared_literature_review.md](research/plastic_shared_literature_review.md)。

每阶段顺序为：当前数据和受限回放进行 CE 骨干训练；固定 anchor 累积新到样本一次；迁移缺失历史并用已驻留样本的新特征替换对应贡献；得到完整当前坐标矩后，用 `fit_moments` **替换**共享基的旧快照，再重估全部类别预测器。不能用累计 `observe` 再次加入完整快照。

共享基输入直接取迁移核心的增广矩：`G=G_aug[:-1,:-1]`、`C=C_aug[:-1,:]`、`s_x=G_aug[:-1,-1]`、类别计数与 N。检查的不只是 G 的 PSD，还包括 `G-C diag(n)^(-1) C^T` 的 PSD 和总特征和 / 类别质量一致性。该 Schur 补等于真实数据的类内散度，但近似矩可能超过 N 行数据允许的秩，因此只能解释为一致的矩代理，不能伪称是 N 张历史图像的精确似然。

在此基础上中心化并执行第 3 节的共享先验 EM。默认每阶段重置 `Sigma=epsilon I`：若行特征满足 `x_new=x_old A+b`，保持分数的预测器应变为 `w_new=A^(-1)w_old`，并非直接把特征迁移矩乘到 D 上。一般 A 不正交时，原各向同性残差协方差也会改变；非线性更新更不提供这种精确变换。重置避免暗中沿用旧坐标的先验，而历史监督信息仍通过完整 G/C 参与重估。

这里的复用通过“全部历史参与的共享预测器先验”体现。每阶段的 D 可以重新旋转、改变，未追踪持久语义专家。骨干仍由 CE 和回放训练，EB 求解不反传；同数据与随机种子下，骨干训练和迁移矩与原 `history_transport` 一致。端到端或少样本 meta 目标是后续可研究的变体，本轮没有隐式加入。

本轮推导增加了噪声退化诊断。对 C 个中心化一热输出，`Cc Cc^T <= n_max Gc`；在各向同性重置点，`S=(Gc/s²+I/epsilon)^(-1)` 与 Gc 对易，且 `S<=epsilon I`。因此：

```
Q - epsilon I
  <= (epsilon/s²) Gc S [n_max/(C s²) - 1]
```

若 `s²>=n_max/C`，所有待保留特征值都不超过 epsilon，EM 从该初始化无法长出非零 D。代码报告这个充分条件与实际有效秩；其逆命题不成立。极小验证预先用噪声 0.01 覆盖非零分支，正式默认仍沿用冻结版的 1.0。噪声适配、C 个独立高斯输出相对于 C−1 个类别对比的差异，均保留为待研究问题。

资源方面，第四方法当前保留迁移辅助 ridge 头和共享基的重复矩快照，二者均计数。部署使用当前骨干加 EB slope/intercept；`head_ridge` 只影响内部辅助头。没有额外模块生长，也没有无成本 / 轻量性的实测结论。

## 7. 未确定部分

1. 共享先验或模块能否改善后续类别样本效率，而非仅拟合早期已见类。合成测试不能提供泛化证据。
2. 预训练表示的可改善余量是否足够。冻结强基线、同架构联合训练上限与域偏移可能给出不同结论。
3. 迁移的类别依赖、选择偏差、非线性外推及误差累积多大；PSD 只保障代数一致，不保障接近真实旧矩。
4. Episode、正则和调度能否产生复用。专家塌缩、null 绕过及主骨干绕过模块均可能发生，可训练不等于有效。
5. EM、矩存储、可微 ridge、双骨干和 VJP 的实际开销；anchor 和辅助状态必须计入。
6. 新颖性与贡献程度。相同机制明确引用，最终贡献需依靠算法差异、性能、效率或机制证据建立。

实验配置与评测公式见 [PROTOCOL.md](PROTOCOL.md)，实际执行证据见 [验证报告](../validation/REPORT.md)。完整实验尚未启动。
