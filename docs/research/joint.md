# Joint：一次性全类别联合训练参考

实现：`models/joint.py`。本方法是用户要求保留的基础离线参考。它在开始训练前获得全部指定训练类别，训练一个新模型，结束后只评估 Final；不属于历史数据受限的持续学习方法。它通常有助于估计联合训练表现，但不是保证高于所有持续学习算法的数学上界，也不意味着本轮已获得正式成绩。

## 1. 数据访问与模型

正式配置使用 CIFAR-100 的全部100类或 ImageNet-R 的全部200类。继续采用共同的 PILOT 类别顺序和标签重映射；原先十个阶段只定义原始类别协议和输出列顺序，不驱动十次训练。

`incremental_train(data_manager)` 只允许调用一次。它请求 `get_dataset(range(C), source='train', mode='train')`，将全部选定类别训练图像作为同一个离线训练集。稳定 ID 必须唯一，类别必须正好覆盖0至C−1。按规定 epoch 数重复遍历这些图像是合法训练，不把重复遍历误算为新的训练数据。

模型是 `cl27.common.build_backbone` 创建的一份全新原生 timm ViT-B/16，使用固定的 AugReg IN21K→IN1K 预训练来源及其权重哈希。不是从任一持续学习方法的最终模型继续训练。CE 线性头在联合训练开始时，直接为全部C类随机初始化一次；不逐任务扩展或复制旧类行。

`CEClassifier` 直接计算 `head(backbone(image))`，输入线性头的是原生 raw CLS。没有解析特征的 L2 归一化、原型分类器、共享基、历史矩、冻结 anchor、模块库、蒸馏或推理集成。所有骨干原参数和全部线性头参数共同更新。图像预处理复用选定的 PILOT 训练/测试变换，没有额外添加像素均值/标准差归一化。

## 2. 训练目标和默认预算

对全部指定训练数据 D：

`min_(theta,W,b) (1/|D|) Σ_(x,y in D) CE(W f_theta(x)+b,y)`。

每个训练 minibatch 使用全部C个输出计算平均 CE，不提供任务ID，也不对类别阶段做 logit mask。优化复用 `adapt_backbone`，但传入的 replay 对象为空，并把 `replay_batch_size` 固定为0；它不会被更新或持有图像。

默认配置：20 epochs，当前 batch64，AdamW，骨干 LR1e−5、头 LR1e−3、weight decay1e−4；学习率只在这一次离线训练上使用20 epoch cosine。配置可以显式改变小规模正确性验证的预算。此处采用和可塑统计路线、ER控制相同的优化器及 LR 分组，未采用按正式测试成绩选参、提前停止或挑选 epoch。

Joint 不受历史图像回放容量2000或20/类的限制，因为全部训练数据可以同时访问。其配置的 `memory_size` 和 `memory_per_class` 都必须为0，用来明确没有独立回放缓冲区；这不意味着它享有与零回放持续学习相同的数据权限。应在结果表中标注 `offline/all training data`，而不是把缓冲区0误写成 exemplar-free CIL。

相同 epoch 数也不等于相同 FLOPs：Joint 对完整训练并集执行一次统一计划，而 ER 在每个阶段还有旧样本回放、头扩展和 LR 重启。Joint 的功能是离线参考，不是计算预算匹配实验。

## 3. 只评估最终模型

训练过程中不请求测试 dataset/loader，不计算测试准确率，不使用验证图像更新参数。全部优化完成后才请求全部已选类别的测试视图，建立 evaluator，由公共 runner 执行一次最终评估。开发阶段的 `source='test'` 映射到预先划分的训练集留出部分；正式测试拆分仅用于正式最终评估。

报告 `Final`。AIA 与遗忘要求连续学习过程中多个阶段的评估，在这个单次离线训练参考中没有对应含义，应为不适用/空值。不能将一次 Final 当作 AIA，也不能把遗忘填写成0。

实现中的 `_cur_task` 保存最后一个选定类别前缀所对应的原协议阶段编号：正式十阶段为9；20类的10×10开发验证为1；六类、每阶段两类的 synthetic 验证为2。这是结果对齐元数据，不表示执行过此前的逐阶段训练。

## 4. 有界验证与恢复

默认选择 `data_manager.nb_classes` 的全部类别。显式开发/smoke验证可以设置 `joint_max_classes`，但必须是原阶段边界的类别前缀，例如20类；正式配置禁止此限制。`max_tasks` 在 Joint 中被拒绝，避免把一个离线拟合错误解释成多个持续学习任务。

检查点只在完整离线训练完成、`after_task` 后保存。状态包括原生骨干、CE头、预训练来源、选定类别前缀、训练源ID哈希及完成标志。恢复先验证候选模型和元数据，成功后整体替换；错误检查点不改变活跃模型。恢复后的对象不能再次训练，不承诺恢复优化器或中途 epoch。公共 runner 的完成恢复路径保留既有最终评估结果，不重新启动训练/评估；恢复模型本身不会隐式重建 evaluator。

资源报告包括一份骨干和一份 CE头；没有 anchor、历史统计量或回放存储。完整离线训练并集的数据访问权限单独声明，不因没有额外 buffer 而忽略。

## 5. 小规模正确性验证

`../.venv-pilot/bin/python -m pytest -q tests/test_joint.py`：12项检查通过。覆盖：一次读取全部类别并集；完整输出词表；参数与梯度实际更新；每图像训练访问数等于epoch数；训练结束前没有测试请求/读取；Final模型的原生 CE logits；完整阶段前缀；拒绝回放和歧义限制；拒绝重复拟合；只允许完整检查点；来源和非有限权重错误的原子拒绝。

这些检查使用独立生成的微型训练/测试 RGB 图像及随机 tiny token ViT，没有下载预训练权重或运行完整基准。正式 CIFAR-100/ImageNet-R 联合训练成绩尚需之后独立执行。
