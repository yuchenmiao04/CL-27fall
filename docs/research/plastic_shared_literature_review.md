# 第四路线的文献与数学独立审查

审查对象：`plastic_shared_basis`，即 CE 可塑骨干、全历史矩迁移、共享预测器经验贝叶斯读出的阶段式组合。审查日期：2026-11-17。本文区分论文原方法、实际阅读的代码，以及本项目自己的推导；不包含准确率、新颖性或跨任务复用已经成立的结论。完整设计见 [plastic_shared_basis.md](plastic_shared_basis.md)。

## 1. 结论与实施边界

该组合在数学和程序接口上可成立，适合作为保留前三路线之后的第四个候选。必要条件是：迁移结果表达**全部当前坐标历史的替换快照**；计数保持真实到达次数；特征与标签联合矩一致；共享先验在新坐标重拟合；把得到的证据标成代理目标。不能把“全量矩”误写成“获得全部旧图像在当前表示下的精确矩”。

本次推荐保留已实现的窄接口：CE 与回放学习主骨干，任务末迁移矩，随后重置并拟合共享先验。它没有从经验贝叶斯目标反传到骨干，不能称为共享基在指导骨干学习。重置 D 不代表丢弃历史，因为重拟合目标仍含全历史的矩代理；但跨阶段的第 k 列不是可以直接追踪的同一个知识单元。

## 3. 独立数学核对

补充阅读（集成端核对，区别于上表独立审阅）：[Deep Kernel Learning，AISTATS 2016，§4](https://proceedings.mlr.press/v51/wilson16.pdf) 及 [GPyTorch 官方 DKL 教程](https://docs.gpytorch.ai/en/stable/examples/06_PyTorch_NN_Integration_DKL/KISSGP_Deep_Kernel_Regression_CUDA.html) 的模型 forward、Type-II MLE 与优化器参数组。它们给出的启发是把可塑表征与预测器协方差一起理解为函数核 `k_t(x,x')=f_theta(x)^T Sigma_t f_theta(x')`。官方教程明确通过边际目标更新特征提取器；本版本使用 CE 学骨干、随后拟合 Sigma，故没有继承这种端到端耦合。未引入 GPyTorch、SKI 或 GP 推理依赖。

以下为对本项目模型的推导和判断，不归为上述论文已经证明的结论。

### 3.1 联合矩及有限样本限制

记非增广特征矩为 G，类别和为 C，计数 n>0，总数 N。需要 `C1=s`，以及

`H = [[G,C],[C^T,diag(n)]] >= 0`。

其 Schur 补为 `G-C diag(n)^(-1) C^T>=0`，就是类内散度。它比仅要求 G>=0 强。中心化后，目标矩为 `Ty=diag(n)-nn^T/N`，满足 `Ty1=0`；共享基必须使用同一个 N、n、s，而不能在 G 迁移后沿用不相容的 C。

若矩来自真实 N 个有标签样本，类内散度秩≤N−类别数，中心化 G 秩≤N−1。残差总体协方差代理可以超过这些秩，因此它可以是相容的总体二阶矩，却不能声称是某个真实 N 行历史特征表的精确统计量。应保留 `moment_kind='surrogate'`；不通过删掉协方差小特征值来伪装经验样本解释。

### 3.2 代理目标为什么仍可以优化

联合中心化块矩 `Hc=[[Gc,Cc],[Cc^T,Ty]]` 若为 PSD，可因子化成 `[Xtilde,Ytilde]^T[Xtilde,Ytilde]`。于是后验和 log-det 项可视为一个高斯伪观测问题。其行数可能 r>N−1；当前目标保留名义 N−1 的常数项，与因子化伪数据的高斯边际目标仅相差 `−K(N−1−r)log(2πs²)/2`。当 s²固定时，该差值不影响对 Sigma 的优化。

因此固定一阶段代理矩时，EM 代数单调性有清楚的解释；它不是对真实丢弃图像的精确边际似然，也不是把未知特征积分后的完整贝叶斯模型。如果未来同时估计噪声，该常数差将依赖 s²，不能直接继承同一解释。迁移估计误差、回放选择偏差与主骨干的不确定性也没有被后验 S 包含。

### 3.3 坐标改变与截距

对行特征 `x_new=x_old A+b`，若 A 可逆，保持预测函数需要 `W_new=A^(-1)W_old`、`intercept_new=intercept_old-bW_new`，先验协方差应变为 `A^(-1)Sigma_old A^(-T)`。这与特征矩的正向迁移方向不同。

固定底噪 `epsilon I` 在一般非正交 A 下不封闭；直接迁移 D 也不足以迁移整个先验。每阶段从各向同性初始化重新拟合是可解释的保守选择，但不是坐标无关或唯一正确的解法。平坦截距应使纯平移不改变最终分类分数。当前 L2 归一化还会让原始 CLS 的一般仿射变化变成非线性变化，因此仿射 oracle 验证不能被当作真实 ViT 漂移模型成立的证据。

### 3.4 噪声过大会保证共享基不生长

在 reset `Sigma=epsilon I` 下，令 `S=(Gc/s²+I/epsilon)^(-1)`、`M=S Cc/s²`、`Q=S+MM^T/K`。联合矩一致性给出 `CcCc^T<=n_max Gc`，S 与 Gc 对易且 `S<=epsilon I`，所以

`Q-epsilon I <= (epsilon/s²)Gc S [n_max/(K s²)-1]`。

若 `s²>=n_max/K`，所有 Q 特征值≤epsilon，受约束 M-step 不能产生正载荷；之后反复相同 EM 也不能逃离。该条件充分而非必要，低于阈值不保证增长。

因此三张/类、十或二十已见类的小验证中，默认噪声1保证 rank0；这不能证明实现没有学习能力。真正预训练的第四路线验证可预先声明噪声0.01用于检查非零基的执行路径，并报告实际秩；不能据此替换正式设置或声称效果提高。所有路线的默认值保持不变，同时把噪声尺度作为待验证设计风险。

另一个必须明确的尺度：rank0 时本模型等价于带平坦截距的 ridge，`lambda=s²/epsilon`。默认1/0.001对应1000，区别于迁移路线的默认 ridge0.01。比较时应报告这个比例，约简测试只有匹配该比例时才能要求两个头相等。

### 3.5 输出对比和“可复用基”的解释

中心化一热输出满足 `Yc1=0`，实际仅有 K−1 个输出对比。现有模型按 K 个独立高斯输出拟合，包括零公共输出方向；这是明确的模型错设，会影响协方差收缩。一个可研究的后续版本是在 `B^T1=0,B^TB=I` 的 K−1 维输出对比上拟合，再用 `W=M_B B^T` 恢复；其 Q 分母变为 K−1。当前为检验组合本身，建议保留既有模型，不静默加入这一变化。

D 的旋转、符号及重特征值子空间不可识别。应比较 Sigma、子空间和预测功能，而非基向量列号。有效秩大于零、EM 证据上升、图像特征改变，分别是三个不同事实；任何一个都不能单独证明对未来类别有益的复用。

## 4. 具体建议与仍开放的问题

本轮应实现或保留：快照替换 API；联合矩 Schur 检验；固定噪声的代理解释；阶段初始先验重置；完整事务性 core/restore；真实计数、实际有效秩、噪声阈值和迭代记录；辅助 ridge 头与共享头的正则比例；两条分支、复制矩、辅助头及回放的真实资源计数。前三路线保持独立，避免把更换读出与训练骨干轨迹同时改变。

本轮不应自动加入：按测试分数改变噪声；把回放当独立验证；依据“全历史计数很大”声称后验精度可信；把估计矩当真实图像观测反复 `observe`；跨坐标暖启动旧 D；端到端贝叶斯骨干训练。以后可以考虑噪声或先验底噪的统计估计、运输误差感知的似然权重、输出对比模型，但必须重新定义目标并验证，不能只加补丁。

主要开放风险是：小且模型相关的驻留集无法识别任意非线性历史漂移；高维仿射映射受样本秩限制而依赖先验；类均值/残差模型的系统偏差会被大量历史质量放大；共享先验可能产生负迁移；有限 EM 与每阶段重置增加成本且可能尚未优化充分；当前共享基只影响部署读出，没有用于教授可塑骨干。
