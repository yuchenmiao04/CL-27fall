# 共享预测基：实现、推导与依据

本文件对应 `models/shared_basis.py` 与 `cl27/cores/shared_basis.py`。它描述一个待验证的候选方法，不报告 CIFAR-100 或 ImageNet-R 的性能结论。与另外两条可塑表示路线并列比较；本路线刻意冻结骨干，研究共享是否可以发生在预测器空间。

## 1. 研究问题与实现范围

老师提出的主线是有原则地分解预测问题，让所得知识单元在任务流中复用，并允许分解随任务变化而适应。这里采用一个具体实例：不同类别的线性预测器共享一个低秩先验，而不是预先为每个单元指定语义。共享基及旧类预测器可在新任务到来后共同重新估计，数据坐标本身不变。没有外部大模型，也没有人为语义分组。

这是 task-wise Class-IL：当前任务包含一组此前未出现的类，测试在全部已见类中分类，不使用测试任务编号。PILOT 的 DataManager 将类别重排成连续标签；第 t 阶段输出列必须恰好对应 `0,...,C_t-1`。

主比较所用骨干、checkpoint、类别顺序、数据划分与评价方式由仓库的统一协议控制。本方法使用指定的冻结 ViT-B/16；输入是最终 CLS。每张当前训练图像经确定性的 `mode='test'` 训练集变换编码一次；默认逐样本 L2 归一化。`none` 是显式配置的另一种固定特征映射，不在流中切换。完整当前类训练集可以使用，原始历史图像回放量为 **0**。允许其他方法使用协议规定的图像预算，不等于本方法实际保存该预算的图像。

## 2. 模型与充分统计量

令固定特征为 x∈R^d；所有已见训练行组成 X∈R^(N×d)，全已见类别的一热标签为 Y∈R^(N×C)。新类别加入时，为历史标签增加零列；当前新类样本对旧类的目标同样为零。不是把各个任务分别拟合后拼接分类头。

各类预测器的生成假设是

```
y_c = X w_c + 1 b_c + e_c,   e_c ~ N(0, s² I_N)
w_c = D a_c + r_c
a_c ~ N(0, I_K),            r_c ~ N(0, epsilon I_d)
Sigma = D D^T + epsilon I_d, w_c ~ N(0, Sigma)
```

`epsilon>0` 与 `s²>0` 为固定超参数；截距 b_c 使用平坦先验。该高斯回归模型用于一热分类目标，属于工作似然，不是精确的分类生成模型。预测分数可为负，虽然总分在精确计算下为 1，也不能直接称为校准后的类别概率。

跨阶段持久保存如下统计量，使用 float64：

```
G = sum_i x_i x_i^T = X^T X
Cxy = sum_i x_i y_i^T = X^T Y
s_x = sum_i x_i
n_c = sum_i 1[y_i=c],       N = sum_c n_c
```

新任务只累加一次 G、s_x 和 N；扩展 Cxy 后，新类列写入其特征和，旧类列保持原来的类特征和。旧类与新类之间的负样本作用仍通过**全历史 G**进入统一回归问题。多轮 EM 不再次读图，不再次累加样本。

### 2.1 平坦截距的精确处理

记 m=s_x/N、p=n/N。通过统计量计算

```
Gc = G - s_x s_x^T/N
Cc = Cxy - m n^T
tr(Yc^T Yc) = N - n^T n/N
```

其中 Xc=X−1m^T，Yc=Y−1p^T。Gc=Xc^T Xc，Cc=Xc^T Yc。这消去未正则化的截距；最后恢复 `b=p−m^T M`。不能在追加常数坐标后对该坐标使用与普通特征相同的 epsilon 正则，这会改变模型，并破坏特征平移不变性。

给定 Sigma，后验共享协方差与类别权重均值是

```
S = (Gc/s² + Sigma^(-1))^(-1)
M = S Cc/s²
scores(x) = x^T M + b
```

同一个 M 同时包含所有已见类。数值实现利用 Sigma 的 Cholesky 因子 L，构造 `A=I+L^T Gc L/s²`，再通过 Cholesky 解得到 S、M 以及 log|A|，不直接计算 Sigma 的逆矩阵。

### 2.2 为什么基可以更新而历史不失配

需要保持不变的是 x 的坐标，而不是 D。似然关于 w 的全部数据依赖均经过 Gc、Cc、目标散度；这些统计量在固定 x 中精确表示全部历史。更新 D 改变的是预测器先验，随后重新计算**所有**旧类和新类的后验。因此不用把旧统计量近似搬到新特征坐标，也不把旧预测器系数直接留在旧基坐标。

令 `Acode=D^T Sigma^(-1) M`，`R=epsilon Sigma^(-1) M`，则

```
M = D Acode + R
scores(x) = (x^T D) Acode + x^T R + b
```

这是共享预测方向与各类残差共同作用的分解。a_c 是稠密高斯代码，没有稀疏路由；epsilon 分支允许共享基之外的预测成分。因此正式预测器并非强制 rank-K 的头。`class_codes` 返回后验代码均值。`code_only_scores` 仅供诊断：在 `w=D a` 的受限模型下重新拟合后验与截距，不能直接删除残差后沿用原截距。

## 3. 全历史经验贝叶斯拟合

这里积分掉每个 w_c，再用全历史数据估计共享的 Sigma。为了处理平坦截距，在与常数向量正交的 N−1 维观测空间写似然。记 `A=I+Sigma^(1/2) Gc Sigma^(1/2)/s²`，忽略与 Sigma 无关的平坦截距规范常数：

```
ell(Sigma) = -1/2 [
  C ((N-1) log(2 pi s²) + log|A|)
  + (tr(Yc^T Yc) - tr(Cc^T M))/s²
]
```

不能把自由度仍写为 N，或在只用当前任务的后验下更新全历史先验。实现测试将此式与显式构造的 N−1 维观测高斯似然比较。

### 3.1 受约束 EM 的 M-step

E-step 使用上节的 S、M。条件期望二阶矩的类别平均为

```
Q = (1/C) sum_c E[w_c w_c^T | Y] = S + M M^T/C
```

由于所有类别使用相同设计矩阵和噪声，S 相同，不能漏掉 S 或再把它除以 C。M-step 等价于

```
min_Sigma  log|Sigma| + tr(Sigma^(-1) Q)
subject to Sigma = epsilon I + D D^T, rank(D)<=k
```

令 Q 的特征值为 q_1≥...≥q_d。最优可提高的协方差方向与最大特征值对齐；对单个所选方向，代价是 `log(lambda)+q/lambda`，`lambda>=epsilon`。导数给出 `lambda=max(q,epsilon)`。增益随 q 在 q>epsilon 区间增加，因此选择最大的至多 k 个方向。由此

```
D_new = U_k diag(sqrt(max(q_i-epsilon, 0)))
```

这是固定 epsilon 条件下的精确受约束协方差 M-step。使用 sqrt(q_i) 会把 epsilon 再加一遍，无法得到上述最优 Sigma。实现每轮检查似然非下降；超出数值容差的下降报错，而非静默回退成另一种算法。

本实现令 `k=min(basis_rank,d,C−1)`。C−1 来自一热目标中心化后的类别对比数，是当前设计采用的保守结构上限；它不是 D 各列语义可识别的证明，也不是完整协方差估计自由度的普遍定理。诊断字段 `class_identified_rank_cap` 保留了早期命名，应按这里的结构上限解释。只有 q_i>epsilon 的方向有非零载荷，有效秩可能更低。旋转 D→DO、代码→O^T代码不改变 Sigma 或预测；固定特征向量符号仅令结果更可重复，不会消除这种等价性。

每阶段从上一阶段 D 暖启动，默认最多 20 次迭代，以相对似然变化 `<=1e-6` 停止。新阶段重新执行 E/M 步，全部历史在统计上重新参与。有限步、暖启动与非凸协方差模型意味着最终解可能依赖任务顺序；不能把统计量与次序无关偷换为整个经验贝叶斯算法严格次序无关，也不能保证等于任意联合优化的最终解。

## 5. 与 V4 及另外两条路线的关系

V4 的重要诉求是利用全历史统计信息而不保存全部历史图像。本路线保留这一统计诉求，但在**不可变原始特征坐标**里学习共享的预测器先验，回避“表示变了、旧统计量没变”的问题。它不是 V4 动态模块分裂或旧 e-process 验收机制的等价重写。固定 K 表示模型容量上限，EM 有效秩变化不等于已实现按需生长的模块系统。

本路线不更新骨干，不单独保留冻结“尺子”与可塑学习支路。`history_transport` 承担可塑骨干与历史统计迁移；`current_adapted` 保留模块方法的结构。新增第四路线 [plastic_shared_basis](plastic_shared_basis.md) 组合可塑骨干、统计迁移和本节共享先验，但通过独立的完整矩替换接口拟合，目标标为代理。此处的冻结方法和默认配置保留不变；各候选的收益仍需实验检验。

## 6. 配置、持久状态与验证边界

默认配置：`basis_rank=32`，`basis_epsilon=1e-3`，`basis_noise_variance=1.0`，`basis_max_iter=20`，`basis_tolerance=1e-6`，`feature_normalization='l2'`。seed 进入统一协议与 checkpoint，但数值核心本身无随机初始化。没有基于官方测试集选择 rank、epsilon、噪声或停止轮次的路径。

数值核心持久数组是 G、Cxy、s_x、n、D、M、b，大小

```
8 * (d² + 2dC + d + C + dK_eff + C) bytes
```

其中 counts 的 int64 也为 8 bytes。该式计入两项 C（counts 与截距），不计 Python 对象、诊断字符串/列表、暂存数组和骨干参数。骨干参数与 checkpoint 另外计数。训练仍需当前任务特征暂存；这不是历史特征回放。每轮 EM 有 d×d 特征分解和线性系统，直接实现约 O(d³+d²C)，共迭代 I 轮。不能把零反向传播写成零训练成本，d=768 的 CPU 耗时需实测。

原生 wrapper 每阶段检查骨干 SHA-256；若有人修改冻结权重，会在读取新任务数据前报错。所有参数 `requires_grad=False`，提特征与评估均用 eval 模式。checkpoint 包含骨干状态、特征归一化、全部矩、基、类别映射和任务诊断；恢复先验证矩一致性、张量形状与骨干 hash，再提交。父生命周期保存任务计数与全局随机状态。没有保存旧图像或旧特征行。

本轮测试范围：显式联合矩等价、包含平坦截距的广义 ridge 等价、观测空间边际似然等价、受约束 EM 非下降、固定噪声底载荷正确、旧基冻结对照、旋转等价、损坏状态拒绝、原生 PILOT 两阶段类映射、当前图像只读一次、测试数据未参与拟合、骨干及 BatchNorm 状态不变、断点继续一致。测试用合成数据及小网络验证公式与数据访问，不给出真实任务泛化证据。

## 7. 尚不确定与需要实验检验的命题

1. **有意义的跨任务复用是否出现。** 共享 Sigma 的数学存在不等于未来类别更好学。需要未来正式实验比较固定各向同性先验、首任务学基后冻结、持续学基；比较样本效率及新类误差，避免仅以边际似然上升作证据。当前不启动这些完整实验。
2. **共享偏差与残差的权衡。** K 太小可能损失类别区分；epsilon 太大可能让各类残差绕过共享；epsilon 太小可能不利于不相关新类别。可形成负迁移，不能承诺有效秩或性能一定提高。默认值仅用于固定、可复现的候选实现。
3. **分类工作似然失配。** 一热列间相关，而先验按类列独立建模；类别数量增加也改变经验贝叶斯目标。噪声同方差、单位历史样本权重、未采用类别平衡均需检验，不能把证据目标当作 Class-IL 准确率的严格代理。
4. **骨干表达能力上限。** 线性预测器先验无法创造不存在于冻结 CLS 的可分特征。ImageNet-R 的域偏移可能让本路线受限；这正是并列实现可塑骨干路线的原因，不能预先确定哪个数据集获益。
5. **全历史矩的适用范围。** 精确性相对于固定特征、平方损失和当前权重规则。更换归一化、更新骨干、改变历史样本权重都需要额外统计或重新编码，不能沿用当前精确性结论。统计量保存也不自动带来信息论隐私保证。
6. **优化、稳定性与可解释性。** 有限 EM、特征缩放及矩中心化数值误差可能影响解；符号固定与旋转测试只验证模型等价。是否有稳定、可解释的知识单元及更低实际成本，仍需机制与资源测量。
