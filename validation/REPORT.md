- ER：单个可塑 ViT＋CE 头＋受限回放；Joint：同预训练起点、单次离线全类别联合训练，只报 Final。

- 两个数据集的八份候选方法配置、二十份 PILOT 原生 baseline 派生配置、四份新基础对照配置，共32份正式配置；六份合成验证配置。
- 方法总说明、各方法详细数学推导与文献适配说明、第四路线独立阅读 / 代码审查、统一实验协议及受限预训练验证脚本。

## 2. 实际执行的检查

独立 Python 3.10 环境：PyTorch 2.0.1、torchvision 0.15.2、timm 0.6.12、NumPy 1.26.4、SciPy 1.13.1。CPU 本地执行，未使用服务器。

首轮114项、增加第四方法后151项检查均通过。本轮增加基础对照及随机流隔离后，**191项测试通过**、32份正式配置通过协议检查；机器记录见 [verification_summary.json](verification_summary.json)、[JUnit XML](unit-tests.xml)。下表保留原候选方法的检查范围，新基础对照见第3.3节。

| 检查 | 证据及范围 |
| --- | --- |
| 共享预测基数值核心 | 显式联合矩、平坦截距的广义 ridge、观测空间边际似然、受约束 EM、旋转等价及损坏状态拒绝 |
| 迁移数值核心 | 精确当前 / resident 替换、缺失均值与类内散度、直推 / 链式、PSD、bias、cross-fitting 和越界拒绝 |

### 3.1 新增第四方法的真实 ViT 检查

第四方法已通过相同限定数据访问规则的真实原生 ViT 检查：两阶段各十类，每类三张训练及三张 train 留出，一个 epoch，累计 60 张拟合 / 60 张留出。未读取官方 test，也未连接服务器。证据见 [第四方法验证汇总](pretrained/plastic_shared_basis/verification_report.json) 及同目录配置、数据摘要和结果。

- 主骨干两阶段均确有更新，anchor 不变。
- 历史计数与共享基样本数均为 30→60；迁移后的完整快照没有重复加入。
- 共享基实际有效秩为 **4→4**，确认执行了非零共享先验路径；部署调用共享头及平坦截距。
- 骨干阶段的 CE 训练诊断和结束权重 SHA 与此前 `history_transport` 的两阶段记录完全相同，见 [real_body_equivalence.json](fourth_method/real_body_equivalence.json)。共享头没有暗中改变骨干训练目标。
- 本检查预先使用 `basis_rank=4`、`basis_max_iter=2`、`basis_noise_variance=0.01`，正式配置为 rank32、最多20次、噪声1。小噪声由已推导的各向同性退化条件决定，用于覆盖非零分支，没有用留出分数选参。

小子集全部旧图驻留，仍不覆盖真实 ViT 下的非驻留历史近似。该分支由直推 / 链式、小回放、小网络及独立平移 / 仿射 oracle 检查覆盖。有效秩非零也不等于跨任务复用有效，不从该检查报告性能提升。

## 4. 独立复核与本轮修复

不同实现者交叉审阅了三条路线的公式、代码、数据流和文档。发现并修正：

1. 三方法特征归一化配置来源不一，改成公共解析器，冲突拒绝。
2. 当前方法恢复探针从冻结 anchor 复制后错误继承 `requires_grad=false`，会改变后续计算路径；显式恢复主支路梯度状态。
3. 模块 hook 位置与 scale 未绑定 checkpoint，补充结构校验；恢复先验证候选状态，再整体提交。
4. FP32 重编码导致近零历史 Gram 相减产生小负值；全覆盖剩余精确置零，部分覆盖按传播的编码误差预算检查 PSD，超限仍拒绝。该精度预算乘子是实现启发式，不是严格网络误差上界。
5. 回放恢复的逐类预算、词表和样本身份检查不完整，补齐并保证失败不改变原状态。
6. 原生方法有 CNN/NME 双头时只记录 CNN 会混淆比较，改成同时保存原始矩阵并预先指定主头。
7. 补齐 provenance 与可信初始 anchor 绑定，避免恢复后错误归属权重来源；任务读取前检查 anchor 未变。

原始源码摘要核对只发现预期的 README、trainer、factory 差异；其余上游 Python / JSON / Markdown 源保持原样。派生配置保留算法学习率、优化器、轮数及损失参数；EASE CIFAR 步长与 FOSTER CIFAR 存储规则的显式差异见协议说明。

第四方法补充了整快照替换、联合矩 PSD / 类质量、总体代理秩解释、先验坐标重置、噪声坍缩充分条件、匹配 lambda 的 rank0 约简、拟合失败回滚、部署 EB 头、两种预算及迁移模式、原生 CLI 与完整流恢复等检查。独立审查还将高秩总体代理的目标与联合矩因子化后的普通高斯参考计算核对。新增方法复用共享核心时发现一项诊断字符串被同名列表覆盖的问题，已修正，并加入冻结版字段回归断言；没有放宽数学容差。

本轮 ER 公平性审查发现：原确定性特征 DataLoader 即使 `shuffle=false` 也会为 base_seed 消耗全局 Torch RNG，因此额外 anchor 编码会改变下一步头初始化 / 训练顺序。现已给只读编码独立的 generator，加入 RNG 保持和特征输出等价检查；未改动数据、类别顺序、损失、epoch、优化器或回放规则。它会改变历史提交的偶然训练随机轨迹。第3节前两轮原始记录及其配对哈希属于各自历史提交，不能要求它们与本轮新训练哈希相同；本轮配对记录单独存放。

公共 runner 新 checkpoint 绑定该随机流策略。无标记 / 不同标记的旧断点需在对应旧代码下继续，当前 runner 会明确拒绝，避免静默混用两套随机轨迹。ER 和 Joint 均有拒绝旧策略断点的检查，数值核心独立 state 格式未改变。

## 5. 限制与后续检验

- 没有十阶段完整结果、多种子统计或性能优越性结论。合成准确率不作为方法有效性的证据。
- 未运行 ImageNet-R 实际输入。准备后历史划分的身份需要外部来源认证；无内容重叠检查不能单独完成此认证。
- 未完整复现原生 baseline，未确认每张历史论文表的部署头，不把本配置直接等同于文献成绩。
- 小子集中 2000 张容量会保留所有旧图，不能声称其真实 ViT 验证覆盖了非驻留历史迁移；该分支由数值和小网络测试覆盖。
- 共享结构的迁移收益、模块是否被使用、近似历史误差、真实规模运行时间与存储仍需正式实验。
- 与 DPCR 等工作的重叠已明确，方法新颖性不由通过测试推出。
