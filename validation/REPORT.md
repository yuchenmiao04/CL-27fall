## 2. 实际执行的检查

独立 Python 3.10 环境：PyTorch 2.0.1、torchvision 0.15.2、timm 0.6.12、NumPy 1.26.4、SciPy 1.13.1。CPU 本地执行，未使用服务器。

第一轮完整检查 **114 项通过**，覆盖如下。最终可重跑结果、精确依赖和代码摘要以 [verification_summary.json](verification_summary.json)、[JUnit XML](unit-tests.xml) 为准。

| 检查 | 证据及范围 |
| --- | --- |
| 共享预测基数值核心 | 显式联合矩、平坦截距的广义 ridge、观测空间边际似然、受约束 EM、旋转等价及损坏状态拒绝 |
| 迁移数值核心 | 精确当前 / resident 替换、缺失均值与类内散度、直推 / 链式、PSD、bias、cross-fitting 和越界拒绝 |

缓存 VJP 的严格链式法则对比使用 FP64 小网络，避免 FP32 grad/no-grad 内核差异掩盖数学检查；实际 FP32 生命周期另行覆盖。上述“状态精确一致”指被检验的小网络与相同环境，不是跨硬件位级复现保证。

## 4. 独立复核与本轮修复

不同实现者交叉审阅了三条路线的公式、代码、数据流和文档。发现并修正：

1. 三方法特征归一化配置来源不一，改成公共解析器，冲突拒绝。
2. 当前方法恢复探针从冻结 anchor 复制后错误继承 `requires_grad=false`，会改变后续计算路径；显式恢复主支路梯度状态。
3. 模块 hook 位置与 scale 未绑定 checkpoint，补充结构校验；恢复先验证候选状态，再整体提交。
4. FP32 重编码导致近零历史 Gram 相减产生小负值；全覆盖剩余精确置零，部分覆盖按传播的编码误差预算检查 PSD，超限仍拒绝。该精度预算乘子是实现启发式，不是严格网络误差上界。
5. 回放恢复的逐类预算、词表和样本身份检查不完整，补齐并保证失败不改变原状态。
6. 原生方法有 CNN/NME 双头时只记录 CNN 会混淆比较，改成同时保存原始矩阵并预先指定主头。
7. 补齐 provenance 与可信初始 anchor 绑定，避免恢复后错误归属权重来源；任务读取前检查 anchor 未变。

原始源码摘要核对只发现预期的 README、trainer、factory 差异；其余上游 Python / JSON / Markdown 源保持原样。派生配置保留算法学习率、优化器、轮数及损失参数；EASE CIFAR 步长与 FOSTER CIFAR 存储规则的显式差异见协议说明。

## 5. 限制与后续检验

- 没有十阶段完整结果、多种子统计或性能优越性结论。合成准确率不作为方法有效性的证据。
- 未运行 ImageNet-R 实际输入。准备后历史划分的身份需要外部来源认证；无内容重叠检查不能单独完成此认证。
- 未完整复现原生 baseline，未确认每张历史论文表的部署头，不把本配置直接等同于文献成绩。
- 小子集中 2000 张容量会保留所有旧图，不能声称其真实 ViT 验证覆盖了非驻留历史迁移；该分支由数值和小网络测试覆盖。
- 共享结构的迁移收益、模块是否被使用、近似历史误差、真实规模运行时间与存储仍需正式实验。
- 与 DPCR 等工作的重叠已明确，方法新颖性不由通过测试推出。
